This build includes FFmpeg and LAME. Each retains its own license.
It decodes AAC, ALAC, FLAC and PCM audio and encodes AAC and MP3.
Video streams are discarded during audio extraction.
The WebAssembly binary is compatible with the pinned CDN core loader for
the page's conversion command. The ffprobe API is not included.

Build with Emscripten 3.1.40 activated, Node.js, Git, curl, GNU make and
pkg-config available. Restore the code blocks in source/build.sh.md and
source/align-abi.mjs.md as build.sh and align-abi.mjs in the same directory.
From an empty working directory run bash with the path to build.sh.
The output is ffmpeg-core-audio.wasm, distributed as ffmpeg-core-0.12.10.wasm.
